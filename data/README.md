# Input data

Put the input video here when running the local pipeline. By default,
`run_video.py` looks for `data/parking1.mp4`; update `INPUT_VIDEO` in that
script to use another filename. Video files are ignored by Git because they
can be large and may not be yours to redistribute.

The video used for this project is available [here](https://mega.nz/file/4w0UCRyJ#TV55n4q-1j4jLCHtT_jmDZjMGdvny0-4Nlj8hAImd7Y).
